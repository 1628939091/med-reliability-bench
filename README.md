# MedReliability-Bench — 医学多模态 VLM 可靠性评测基准

> 应用统计学研一 · 项目一 · 可拓展为毕业论文 + NLP/多模态顶会短文

## 一句话介绍

给医学多模态大模型（VLM）做"体检"的框架：**它是不是真的在看图？答案稳定吗？置信度可信吗？** 全部用统计方法量化，零 GPU 也能跑（API 推理 / Mock 演示）。

## 它解决什么问题（论文动机）

2025–2026 年多篇医学 VQA 研究发现了一个尴尬的现象：

1. **模态坍缩**：给模型一张空白图，准确率几乎不降——说明模型根本没看图，全靠语言先验在猜；
2. **语言捷径**：纯文本输入和图文输入的答案高度一致；
3. **答案不稳定**：同一道题问 5 次，答案可能不一样；
4. **校准差**：模型说"我 95% 确定"，实际正确率远没有 95%。

医疗场景里这四个问题每一个都是事故隐患，但现有医学 VLM 评测（如 MedVLMBench）只报准确率，**没有系统的扰动分析、没有统计校准、没有一致性指标**——这就是本项目（也是你的论文）的切入空隙。

## 已有实测结果（SLAKE 测试集 355 道闭集题 × 7 扰动 × 3 重复 = 7,455 次调用）

被测模型：`Qwen/Qwen3-VL-8B-Instruct`（硅基流动托管，temperature=0）

| 扰动 | 准确率 | 95%CI（按题聚类） | Yes 率 | 相对原图 |
|---|---|---|---|---|
| 原图 | **0.684** | [0.638, 0.732] | 0.590 | — |
| 高斯噪声 | 0.660 | [0.613, 0.711] | 0.581 | −0.023 |
| 上下翻转 | 0.669 | [0.620, 0.717] | 0.571 | −0.015 |
| 降分辨率 | 0.638 | [0.590, 0.687] | 0.466 | −0.045 |
| **图像置空** | **0.449** | [0.397, 0.498] | **0.122** | −0.235 |
| 换成别的题的图 | 0.479 | [0.427, 0.531] | 0.355 | −0.205 |
| 完全不给图 | 0.480 | [0.431, 0.532] | 0.577 | −0.204 |

**三个反直觉的结论（详见 `outputs/analysis_<运行名>.md`，由 `analyze_full.py <checkpoint>` 生成）：**

1. **聚合坍缩差 Δ=+0.235 是假象**：按答案方向拆开，gold=Yes 的题 Δ=**+0.712**、gold=No 的题 Δ=**−0.230**。图像的价值几乎全在"让模型敢答 Yes"；对"No 类"问题，不给图反而更准（条件反射答 No 蒙对）。单一 Δ 会同时低估图像作用、掩盖模型的"假会"。
2. **"置空图" ≠ "不给图"**：两者准确率接近（0.449 vs 0.480），但 Yes 率差 4.7 倍（0.122 vs 0.577）、答案熵 0.535 vs 0.983 bit。模型把空图读作"没有证据→答 No"，把缺图读作"从文字推断"。**评测设计混用这两种条件会得到互相矛盾的结论。**
3. **校准是最大短板**：平均置信度 0.961 vs 实际准确率 0.684，ECE **0.277**，1,058/1,065 条记录挤在置信度 0.9–1.0 区间——置信度几乎无区分度，不能用于临床决策阈值。

> 上面三条在换模型后的命运不同（见下节）：①的「Yes 方向」复现、「No 方向为负」**跨模型不复现**（跨数据集复现）；②复现；③的 **ECE 数值不复现**，但「置信度不可用」这一结论以更强的方式复现。
>
> **还有第 4 个发现，聚合指标里看不见，必须按提问极性分层才暴露**——见下文「否定式提问陷阱」：Qwen 在 `Does the liver look normal?` 这类否定式提问下把 73% 的异常判成正常，而同一批影像换成 `Is there an abnormality?` 就正常。这是本项目对医学 VLM 评测最有价值的一条。

### 跨模型复现：同 355 题再跑一个非 Qwen 家族模型

第二个模型选 `zai-org/GLM-4.5V`（智谱，与 Qwen 不同家族，避免「同门师兄弟」式的伪复现），同一份 355 题 × 7 扰动 × 3 重复。全量 **7,450/7,455** 条（5 条 `text_only` 因网络超时重试耗尽被跳过，占 0.07%）。

| 指标 | Qwen3-VL-8B | GLM-4.5V | 读法 |
|---|---|---|---|
| 原图准确率 | 0.684 | **0.793** | GLM 更强，但仍只比常数基线高 0.286 |
| 置空准确率 | 0.449 | 0.514 | 都掉到常数基线（0.507）附近 |
| 坍缩差 Δ | +0.235 | +0.280 | 两个模型都显著 > 0 |
| Δ（gold=Yes） | +0.712 | **+0.516** | **强复现**：图像价值集中在「敢答 Yes」 |
| Δ（gold=No） | **−0.230** | +0.050（CI 含 0） | **不复现**：No 方向是 Qwen 的特性 |
| 置空 Yes 率 | 0.122 | 0.266 | 都塌向 No |
| 缺图 Yes 率 | 0.577 | 0.667 | 都偏向 Yes |
| pass^3 | 0.676 | 0.763 | |
| ECE | 0.277 | **0.083** | **不复现**，GLM 校准明显更好 |
| 拒答率 | 0.0% | 0.0% | 两家都不拒答 |

**四条可证伪假设的复现矩阵（判定阈值固定，不看是哪个模型/数据集）：**

| 假设 | Qwen·SLAKE | GLM·SLAKE | Qwen·VQA-RAD | 复现 |
|---|---|---|---|---|
| H1 模态坍缩（置空后掉到常数基线） | ✅ | ✅ | ✅ | **3/3** |
| H2 图像价值不对称（ΔYes ≫ ΔNo） | ✅ | ✅ | ✅ | **3/3** |
| H3 置空 ≠ 缺图 | ✅ | ✅ | ✅ | **3/3** |
| H4 校准崩塌（ECE>0.15 且过信>0.15） | ✅ | ❌ | ✅ | 2/3 |

> H1 的判定几乎同义反复（灰图让模型恒答 No，准确率自然等于「全答 No」基线），真正有信息的是「原图是否显著高于基线」，见下文「否定式提问陷阱」上方的分题型表。

### 跨数据集复现：Qwen3-VL-8B × VQA-RAD（300 题 × 180 图 × 7 扰动 × 3 重复 = 6,300 次）

VQA-RAD 是开放式问答数据集，这里用 `gen_subset_vqarad.py` 抽了 300 题的分层子集，闭集化成 `A. No / B. Yes`（152:148 均衡），图片零缺失。

| 指标 | Qwen · SLAKE | Qwen · VQA-RAD | 读法 |
|---|---|---|---|
| 原图 acc | 0.684 | 0.676 | 同一水平 |
| 置空 acc | 0.449 | 0.539 | VQA-RAD 的基线本身就偏高 |
| 坍缩差 Δ | +0.235 | **+0.137** [+0.053, +0.210] | 变小但仍显著 |
| Δ（gold=Yes） | +0.712 | **+0.471** | 方向强复现 |
| Δ（gold=No） | −0.230 | **−0.189** | **复现**：Qwen 的 No 方向为负，跨数据集成立 |
| 置空 Yes 率 / 缺图 Yes 率 | 0.122 / 0.577 | 0.221 / 0.661 | H3 复现 |
| ECE | 0.277 | 0.277 | 一字不差 |

聚合 Δ 变小只是因为它取决于 Yes 题占比，不是模型行为变了；拆开看结构完全同构。**「Qwen 的 No 方向为负」在跨数据集上复现，而在 GLM 上不复现**——所以它仍是模型特性而非任务特性。

**「置空 ≈ 换错图」：先修复了一个实现级 bug，然后发现这个比较本身就是陷阱。**

初版 `runner.py` 里 swap 是这么选图的：

```python
other_img = next((x.image for x in samples if x.image != s.image), s.image)
```

`next()` 取的是列表里**第一张不同的图**——所有题都被换成了同一张固定图片。所谓「换成别的题的图」，实际是「换成某一张固定的图」。症状是 VQA-RAD 上 swap(0.613) 反而比 blank(0.539) 高 7.4 个点：那张固定图恰好能答对一批「是不是 CT」类模态题。**当时 SLAKE 上 swap≈blank（差 0.003）纯属运气。**

修复后按题随机抽图（`random.Random(f"swap|{sid}")`，可复现、永不换到自己；300 题会换到 145 张不同图片），三个运行全部重测：

| 运行 | 置空 acc | 换错图 acc | 差值 | 配对 n | 只有换错图对 | 只有置空对 | McNemar p |
|---|---|---|---|---|---|---|---|
| Qwen3-VL-8B · SLAKE | 0.449 | 0.479 | +0.030 | 1065 | 225 | 193 | 0.129 |
| GLM-4.5V · SLAKE | 0.514 | 0.520 | +0.007 | 1065 | 209 | 202 | 0.767 |
| Qwen3-VL-8B · VQA-RAD | 0.539 | 0.611 | +0.072 | 900 | 179 | 114 | **0.0002** |

两个 SLAKE 运行不可区分，但 VQA-RAD 上换错图**显著更高**。这条不能当普适结论——而查清「为什么」之后，原来的解释也被推翻了。

**灰图不是「零信息」，是「钉死在 No 上」。** SLAKE 多数题型的置空 Yes 率是 **0.000**（灰图 → 一律答 No），所以置空准确率**精确等于该子集的「全答 No」基线**。一旦某题型 gold 偏 Yes，恒答 No 就成了主动答错：

| 运行 | 题型 | gold Yes 占比 | 常数基线 | 置空 acc | 置空−基线 | 换错图 acc | 换错图−基线 |
|---|---|---|---|---|---|---|---|
| Qwen · SLAKE | Abnormality | 0.449 | 0.551 | 0.231 | **−0.320** | 0.456 | −0.095 |
| Qwen · VQA-RAD | MODALITY | 0.250 | 0.750 | 0.300 | **−0.450** | 0.700 | −0.050 |

VQA-RAD 上「换错图 > 置空」的全部来源就是这个：**不是错图带来了信息，而是灰图在 gold 偏 Yes 的题型上演成了负分。**

**所以正确的参照物是「该题型自己的常数基线」，不是另一个坏条件。** 按题型扣掉基线后（单侧二项检验，H0 = 该题型常数基线）：

- **换错图几乎从不显著超过基线**（唯一例外：VQA-RAD 的 PRES 题型 0.650 vs 0.578，p=0.0007——VQA-RAD 只有头/胸/腹三部位，随机换图有 1/3 概率同部位）；
- **原图有 6 个题型显著超过基线**：Qwen 的器官有无（0.818 vs 0.506）、模态（0.797 vs 0.522）、位置（0.800 vs 0.533）、尺寸（0.709 vs 0.538）、病灶有无（0.675 vs 0.578）；GLM 则是**全部 6 个题型都超**，包括异常判读（0.646 vs 0.551，p=0.0006）。

**结论从「模型只感知图像存在性」修正为：视觉通路确实被使用，但接地深度因模型而异。** 详见 `outputs/compare_models.md` 第四节。

### 否定式提问陷阱：最值得写进论文的一条

Qwen 在 Abnormality 题型上「等效常数预测器」（0.520 vs 基线 0.551）。继续往下拆才发现，**不是看不见病灶，是被否定式提问把极性带反了**：

- 直接式 `Is there an abnormality in the liver?` → 答 Yes 表示**有异常**
- 否定式 `Does the liver look normal?` → 答 Yes 表示**正常**

| 运行 | 问法 | n | 准确率 | 按自身 Yes 率的随机期望 | 敏感度（异常判出） | 特异度（正常判对） |
|---|---|---|---|---|---|---|
| Qwen · SLAKE | 否定式 | 165 | 0.430 | 0.522 | **0.273** | 0.535 |
| Qwen · SLAKE | 直接式 | 129 | 0.636 | 0.499 | **0.606** | 0.667 |
| GLM · SLAKE | 否定式 | 165 | 0.648 | 0.515 | 0.591 | 0.687 |
| GLM · SLAKE | 直接式 | 129 | 0.643 | 0.504 | 0.803 | 0.476 |

同一批影像、同一个判断任务，只换问法：

- **Qwen 的敏感度从 0.606 掉到 0.273（漏诊率 73%）**，而准确率 0.430 **低于**按自身 Yes 率随机作答的 0.522——回答与金标**负相关**，是极性理解反了，不是看不见病灶。
- **GLM 也掉了 0.21**（0.803 → 0.591），但极性没反（0.648 > 随机 0.515），只是判读变弱。

**评测学意义**：只报聚合 accuracy 会把两种效应抵消掉——Qwen 看起来只是「比 GLM 差一点」，实际上它在否定式提问下把 73% 的异常判成正常。临床里「这个结节正常吗」和「有没有异常」本来就是混着问的。**报告医学 VLM 的异常判读能力必须同时给敏感度、并按提问极性分层**；只看 accuracy 是失职。

**H4 的细化**：ECE 差异（0.277 vs 0.083）会让人以为「Qwen 校准差、GLM 校准好」。但把置信度当分类器看，区分对错的 AUC 只有 **0.696 / 0.594**，唯一取值数只有 **6 / 7** 个——两家的 confidence 都是被量化成两三档的「口头禅」，不是概率。所以正确表述是「**两家的置信度字段都不能用于临床阈值**」，而不是「GLM 校准好」。

> 统计口径：同一题问 3 次不独立，置信区间用**按题目聚类的 Bootstrap**（B=2000）；配对比较用 McNemar 精确检验（p=4.3e−09）。子组 n<20 标 ⚠️ 仅作描述。

### 稳健性压力测试：这些结论经得起换口径吗

355 道题只对应 **96 张唯一图像**（平均一图 3.7 题），所以「按题目聚类」可能仍偏乐观。我们把三种聚类口径并排跑了一遍（`analyze_robust.py`，零 API 调用）：

| 指标 | 聚类单位 | 点估计 | 95%CI | CI 宽度 |
|---|---|---|---|---|
| 原图准确率 | 记录级（假装 1,065 条独立） | 0.684 | [0.655, 0.711] | 0.056 |
| 原图准确率 | 题目聚类（355 题） | 0.684 | [0.638, 0.732] | 0.095 |
| 原图准确率 | **图像聚类（96 图）** | 0.684 | [0.634, 0.735] | 0.102 |
| 坍缩差 Δ | 记录级 | +0.235 | [+0.193, +0.276] | 0.083 |
| 坍缩差 Δ | 题目聚类 | +0.235 | [+0.163, +0.304] | 0.141 |
| 坍缩差 Δ | **图像聚类** | +0.235 | [+0.171, +0.302] | 0.131 |

**四条结论：**

1. **点估计一度不变**，最保守口径下 Δ 的 CI 仍严格排除 0；图像层符号检验（60 图优于 / 14 图相反，p=6.2e−08）独立佐证。结论不依赖统计技巧。
2. **设计效应可乘法分解**：deff = **3.30 = 3.0（重复的代价）× 1.10（聚类的代价）**。也就是说 7,454 次调用的统计效力约等于 **322 个独立观测**——「7455 次评测」是把重复当样本量，属于口径虚高；而「355 题」只打了 9% 的折，站得住。
3. **ICC(1)=0.093 推翻了一个直觉**：同一张图上的不同问题并不同质（「有没有肺」「有没有肝」「是 CT 吗」考的是不同能力维度），所以图像聚类几乎没有放宽 CI。聚类不是魔法，它只在真的存在簇内相关时才起作用。
4. **Holm 校正砍掉一个假发现**：Plane（解剖平面）类 Δ=−0.240 看似是「给图反而更差」的漂亮异常，但 n=25、校正后 p=0.86 —— 7 个子组做 7 次检验，撞上一个 p<0.05 的概率本来就有 30%。不做这步就会把噪声写进简历。

**模态分层的原结论已被自己推翻（保留在案作为教训）**：初版写的是「X-Ray Δ=+0.330 最高 > CT +0.217 > MRI +0.155，说明模型在 X 光上最依赖语言先验」。这句话有**两处错误**，第二次跑模型时才暴露：

1. **方向读反了**：Δ 是「原图 − 置空」，Δ 大意味着图片一撤掉就掉得狠，也就是**更依赖图像**，不是更依赖语言先验。
2. **没扣子集基线**：X-Ray 的 Yes 金标占 55.2%，所以「永远答 No」在这个子集上只有 0.448（不是 0.507）。子集基线低，置空准确率自然低，Δ 自然高——排序里有一半是答案比例，不是坍缩幅度。

扣掉子集基线后看「置空 acc − 子集基线」：CT **−0.005 / +0.034**、MRI **0.000 / +0.005**（Qwen / GLM），全部落在 ±0.05 内 → **两个模型在 CT 和 MRI 上都完全退化成常数预测器**。真正异常的只有 Qwen 的 X-Ray：**−0.205**，比常数预测器还差 20 个点（GLM 在同处是 −0.045，正常）。所以正确的说法是「**Qwen 在 X 光题上不是不看图，而是看图之后主动答错**」——这是模型缺陷，不是数据特性。

## 快速开始

```bash
# 1. Mock 演示（零成本，无需任何 API/网络/GPU）
python run_demo.py

# 2. 接真实模型：编辑 configs/demo_config.json，把 mock 条目换成：
# { "backend": "api", "name": "Qwen-VL-Max",
#   "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
#   "api_key": "sk-你的key", "model": "qwen-vl-max" }
python run_demo.py configs/demo_config.json

# 可选依赖：pip install pillow  （启用噪声/翻转/低分辨率像素级扰动）
```

## Mock 演示会看到什么

配置里 4 个 Mock 模型分别模拟真实 VLM 的 4 种典型缺陷，报告会自动诊断出来：

| Mock 模型 | 模拟的缺陷 | 报告中的信号 |
|---|---|---|
| 只看文字 | 模态坍缩 | 坍缩差 Δ = 0.000 |
| 正常看图 | 无（对照组） | Δ 显著 > 0，ECE 很小 |
| 答案不稳定 | 推理随机性 | pass^5 只有 0.05 |
| 过度自信 | 校准失败 | ECE = 0.3+ |

**这段"Mock 复现了真实论文报告的现象"本身就是你论文 Method 章的有效性验证（sanity check）。**

## 怎么换成真实实验数据

**已经写好了转换器**：`medbench/adapters.py`，一行命令把公开数据集转成本项目的 JSONL。

```bash
# 不下载数据也能先验证代码正确（造结构相同、内容假的源数据，跑通四个转换器）
python -m medbench.adapters --selftest

# SLAKE（中英双语，主力数据集；--lang zh 只取中文题）
python -m medbench.adapters --dataset slake --src /path/to/SLAKE --out data/real --lang zh
# VQA-RAD
python -m medbench.adapters --dataset vqa_rad --src /path/to/VQA_RAD --out data/real
# PathVQA（提供"病理"这个不同模态，用于分层对比）
python -m medbench.adapters --dataset pathvqa --src /path/to/PathVQA --out data/real
# IU X-Ray：不做选择题，输出"同患者正位+侧位"配对清单
python -m medbench.adapters --dataset iu_xray --src /path/to/IU --out data/real
```

三个已经定好的设计决定（写论文时要交代）：

1. **只取闭集题**。开放式题（"这是什么器官"）无法用选项准确率评估，混进来会让"坍缩差"
   变成"生成文风差异"。丢弃数量脚本会打印，作为数据筛选口径报告。
2. **选项标签与文本分离**：选项文本嵌进 `question`，`options` 只放标签 `A/B/C/D`。
   这样 Mock 后端（用 options 做配对实验）和真实 API 后端（需要看到选项文本）都不用改。
3. **保留 `meta`**（器官/模态/语言/答案类型/同图 id）。分层统计、混合效应模型全靠这几个字段——
   丢了就只能报总分，论文第 4 章的异质性分析做不了。

数据格式如下（`meta` 可选但强烈建议保留）：

```json
{"id":"slake-test-1","question":"肝脏是否增大？\n选项：A. 是  B. 否","options":["A","B"],
 "answer":"A","image":"/abs/path/imgs/xmlab1/source.jpg","category":"image_dependent",
 "meta":{"dataset":"slake","lang":"zh","modality":"CT","organ":"Liver","same_image":"xmlab1/source.jpg"}}
```

- `image_dependent`：看图才能答的题（扰动实验主要看这类）
- `text_prior`：语言先验即可猜的题（语言捷径分析看这类）
- 二元选择设计是为了统计功效：40 题二元题 ≈ 100 题开放题的信息量，且 McNemar 检验直接可用
- 注意：`category` 在真实数据里**不应该靠人工假设**，更严谨的做法是用 `text_only` 扰动实测
  "不给图能否答对"来**经验分层**——这是论文方法章的一个小贡献点
